QU — Playground

Beim Laden dieser Seite wurde bereits window.qu angelegt — eine echte, voll funktionsfähige Qu-Instanz (Spaces, Netzwerk, Dateien). Zusätzlich stehen ALLE Basis-Bausteine aus src/index.js als globale Namen zur Verfügung (Qu, QU_PRESETS, createNetworkPlugin, createWebSocketChannel, QuRuntime, QuStore, …) — die Konsole ist kein Sandkasten mit nur einer vorgefertigten Instanz, sondern derselbe Import, den auch diese Seite selbst nutzt. Öffne die Browser-Konsole und tippe direkt await qu.own.get('note').put('hallo') oder baue mit await Qu.create() eine ganz eigene, zweite Instanz. Jeder Codeblock unten ist copy-paste-lauffähig.

Setup (bereits ausgeführt)

Dieser Code lief schon, bevor die Seite fertig gerendert war.

import * as QuLib from '/src/index.js';
Object.assign(window, QuLib); // ALLE Exporte (Qu, QU_PRESETS, createNetworkPlugin, QuRuntime, ...) global
const { Qu, QU_PRESETS, createFileHandlerPlugin, MemoryFileStorageAdapter } = QuLib;

const qu = await Qu.create({
  plugins: [...QU_PRESETS.network, createFileHandlerPlugin({ fileStorage: new MemoryFileStorageAdapter() })],
});
window.qu = qu; // Konsole: qu.get(...), qu.own, qu.createSpace(...), qu.connect(...), …

1 · Lesen & Schreiben — get/put/set

put() ist "letzter Schreiber gewinnt" (ein Wert an einer festen Adresse), set() hängt kollisionssicher an (mehrere Schreiber, ein Eintrag pro Aufruf). 

await qu.own.get('note').put('hallo Welt');       // LWW — überschreibt den vorigen Wert
const q = await qu.own.get('note');                // lesen: QuBit { value, ts, writer, ... } oder null
console.log(q.value);

await qu.own.get('todos').set({ text: 'Milch kaufen' }); // set() statt put(): kollisionssicherer Eintrag
await qu.own.get('todos').set({ text: 'Brot kaufen' });

live über .on() beobachtet: (leer)

2 · Live beobachten — on() / map()

on(cb) hört auf GENAU diesen Knoten, map(cb) auf seine direkten Kinder (z. B. alle Einträge einer set()-Sammlung). Beides bleibt aktiv, bis die zurückgegebene Funktion aufgerufen wird. 

const unsubscribe = qu.own.get('note').on((q) => console.log('note ist jetzt:', q?.value));
const unsubscribeTodos = qu.own.get('todos').map((q) => console.log('todo:', q.value.text), { initial: true });
// … später: unsubscribe(); unsubscribeTodos();

3 · Spaces & Zugriffsrechte

Ein Space hat ein eigenes Manifest (admins/writers/readers). Ohne createSpacesPlugin() (hier schon Teil von QU_PRESETS.network) darf nur der eigene ~fingerprint-Bereich beschrieben werden. 

const space = qu.createSpace({ writers: [qu.fingerprint], readers: ['*'] }); // '*' = jeder darf lesen
await space.ready; // auf das erste, ACL-setzende Schreiben warten
await space.get('title').put('Mein Space');
console.log(space.id); // fest — merken, um später erneut mit qu.get(space.id) dorthin zu navigieren

4 · Referenzen — key:// automatisch folgen

Ein Wert der Form key://<pfad> wird von await/put/ set/on/map transparent aufgelöst — einmalig, beim jeweiligen Aufruf, nicht mitten im Pfad. {'{'} raw: true {'}'} schaltet es ab. 

// keyRef ist bereits global (window.keyRef, s.o.)
await qu.own.get('team-alias').put(keyRef(qu.userSpaceId)); // Referenz statt Kopie
const resolved = await qu.get(qu.userSpaceId).get('team-alias'); // folgt automatisch bis zum Ziel-QuBit
console.log(resolved.id); // === qu.userSpaceId, nicht 'team-alias'

5 · Dateien

put() erkennt Uint8Array/File/Blob automatisch und chunked+manifestiert statt roh zu schreiben — vorausgesetzt ein FileHandlerPlugin ist installiert (hier bereits der Fall). 

const file = document.querySelector('#file-input').files[0];
await qu.own.get('avatar').put(file);
const manifest = await qu.own.get('avatar');
console.log(manifest.value); // { name, size, mime, chunks, hash, ... }

6 · Netzwerk: mit dem Relay verbinden

Derselbe WebSocket-Relay, der diese Seite ausliefert (index.js). Der Handshake beweist zuerst den Fingerprint der Gegenseite, danach ist die Verbindung eine normale DefaultReplication. pushTopics ist, was DIESE Verbindung selbst nach außen pusht. 

// createWebSocketChannel ist bereits global; createNetworkPlugin ist auf qu schon installiert
const channel = createWebSocketChannel(`${location.protocol === 'https:' ? 'wss:' : 'ws:'}//${location.host}/relay`);
await channel.connect();
const repl = await qu.connect(channel, { pushTopics: ['playground/'] });
nicht verbunden

7 · Eine zweite Instanz (Bob) — dynamisches Subscribe

bob kennt 'playground/' nicht als eigenes pushTopics — er bekommt es trotzdem live zugestellt, weil .map() beim Aktivieren automatisch ein qu.subscribe an den Relay schickt (allowDynamicSubscribe, siehe README Abschnitt 3). Erst 6 · Netzwerk oben verbinden, dann hier bob starten. 

const bob = await Qu.create({ plugins: QU_PRESETS.network });
const channelBob = createWebSocketChannel(relayUrl());
await channelBob.connect();
await bob.connect(channelBob, { pushTopics: [] }); // bob pusht nichts eigenes — reiner Leser

bob.get('playground').get('messages').map((q) => console.log('bob sieht:', q.value.text));
// ^ löst automatisch repl.ensureSynced('playground/messages') aus — sync + live subscribe, einmalig

await qu.get('playground').get('messages').set({ text: 'hallo bob' });
