QU — Beispiele

Vier kurze, fokussierte Module unter examples/ — jedes trennt die Logik (*-lib.mjs) bewusst von jeder Oberfläche, damit man sie ganz ohne Browser lesen und mit node --test nachvollziehen kann. Für "im Browser anfassen" siehe stattdessen das Interaktive Lab oder den Playground.

ToDo-Liste teilen

Ein Space als teilbare Liste: Link = Space-Id, Schreibrecht per Fingerprint gewähren.
examples/todo-lib.mjs · Test ansehen

Forum mit Zeit-Sharding

Wachsende Collections ohne "alle Posts für immer" abonnieren — Posts pro Monats-Bucket.
examples/forum-lib.mjs · Test ansehen

App-Space über echten Relay

Offener vs. mitgliederbeschränkter App-Space, verbunden über einen echten WebSocket-Relay.
examples/app-space-lib.mjs · Test ansehen

Mehrere Sub-Spaces indexieren

Ein App-Space verweist auf mehrere Boards/Listen — "App hat viele Spaces" statt "App ist ein Space".
examples/space-index-lib.mjs · Test ansehen
