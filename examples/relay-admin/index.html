Rate-Limit

Schreibvorgänge pro Fingerprint, innerhalb eines Zeitfensters. Ohne konfiguriertes Rate-Limit (QU_RATE_LIMIT=0) zeigt dieses Panel keine Werte an.

Kein Rate-Limit auf diesem Relay konfiguriert.

Verbindungslimit

Maximale Anzahl gleichzeitig verbundener Fingerprints, optional zusätzlich auf eine feste Fingerprint-Liste beschränkt. Leeres Limit-Feld = kein Limit; leere Liste = keine Einschränkung.

Plattform-Module

Optionale QUniverse-Shell-Features (Kontaktliste, CMS-Startseite, Benachrichtigungen, Verzeichnis, Incognito-Identitäten) — anders als eine einzelne App (App-Verzeichnis): diese schalten keine eigene App an/aus, sondern welche Bausteine eine Ökosystem-Shell überhaupt installiert/rendert. Ein Relay ohne Plattform-Registry (platformRegistry nicht übergeben) zeigt hier keine Module an.

    Keine Plattform-Registry auf diesem Relay konfiguriert.

    App-Verzeichnis

    Eine Admin-Identität sieht deaktivierte Apps im App-Verzeichnis immer (zum Verwalten/ Reaktivieren). Diese Einstellung entscheidet, ob eine NICHT-Admin-Identität sie dort auch sieht (klar als "deaktiviert" markiert) oder ob sie komplett verschwinden — öffentlich lesbar, nur von einem Admin änderbar (wie Theme unten, kein verschlüsseltes Admin-Kommando).

    • Deaktivierte Apps für alle sichtbar
      relay-config/show-disabled-apps

    Theme

    Deployment-weites Farbschema (CSS Custom Properties), das jede App/jeder Service auf diesem Relay lesen kann. Öffentlich lesbar, nur von einem Admin änderbar — ein plain signierter Write auf relay-config/theme, kein verschlüsseltes Admin-Kommando (Farbwerte sind nicht geheim).
